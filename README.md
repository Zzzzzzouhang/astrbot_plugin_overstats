# astrbot_plugin_overstats

一款为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 打造的守望先锋数据查询插件。本插件作为桥梁，连接了由网易大神接口驱动的 [Overstats](https://github.com/AddOneSecondL/Overstats) 后端服务，为您的群聊带来全方位的守望先锋战绩与资讯查询体验。

> ⚠️ **声明**：本插件的大部分代码并非人类编写（由 AI 协作完成），如有未能预料的异常，欢迎提交 Issue。

## 🌟 核心特性

* **极速绑定**：支持 `/绑定` 指令。在群聊中直接发送符合规范的战网 ID（如 `Player#12345`），插件会自动截获并自动完成账号绑定。
* **全景数据大盘**：
    * **战绩总结**：提供今日、昨日、周度大数据总结卡片。若今日无对局，会自动尝试拉取昨日总结。
    * **对局分析**：支持最近对局详情。更可通过在群聊中**直发数字 1~20**，一键拉取单局多图的超详细战绩分析。
    * **天梯评估**：历史历届段位追溯、快速/竞技英雄云图（Treemap 矩形树图）、开黑同玩胜率、天梯强度指数评估。
* **国服/外服资讯**：全服段位分布图、Ban/Pick 胜率排行、每周精选商店、实时赛事对阵图、赛季地图池、皮肤搜索、外服版本补丁说明。
* **专精排行榜**：支持按省份/位置查询天梯省榜（Tank/DPS/Support/Open），以及单英雄专精绝活榜。
* **平台动态适配**：原生支持 QQ 官方机器人平台。在官方环境下会自动启用动态 Markdown 按钮标签（`<qqbot-cmd-input>`）并进行编码处理，提供点击交互体验；在其他平台则自动剥离标签转为纯文本，确保格式完美。
* **群组级别配置**：支持按群组单独配置「首次提示后不再提示」和「追加交互提示」两项功能，配置通过 AstrBot KV 存储持久化，重启不丢失。群管理员可通过 `/群设置` 指令管理。

## 🛠️ 前置准备

本插件**仅用于 AstrBot 与 Overstats 后端通讯**。支持两种后端接入模式：

- **一键托管模式（auto）**：插件自动部署并管理 Overstats 后端，无需手动配置后端环境（推荐新手使用）
- **独立链接模式（manual）**：自行在服务器上部署 Overstats 后端，插件通过 API 地址接入（原模式，适合已有后端的用户，或者使用其他服务商服务）


### 一键托管模式（auto）准备

1. 获取网易大神账号的 `role_id` 和 `token`（参考 [Overstats Faststart.md](https://github.com/Zzzzzzouhang/Overstats/blob/main/Faststart.md)）
2. 确保服务器已安装 `git` 并在 PATH 中可用
3. 在 AstrBot 插件配置面板将「后端接入模式」改为 `auto`
4. 在配置面板的「大神账号配置」中添加至少一个账号（填写 role_id 和 token）
5. 在群聊中执行 `/ow部署`，插件将自动完成代码获取、虚拟环境创建、依赖安装、配置生成、服务启动全流程

### 独立链接模式（manual）准备

1. 请前往 [Zzzzzzouhang/Overstats](https://github.com/Zzzzzzouhang/Overstats) 仓库，按照其说明文档完成服务部署
2. 确保 Overstats 后端的 API 端口（默认 `18080`）可以被 AstrBot 所在的服务器正常访问
> ⚠️ 监听全部端口需要在Overstats/config/config.py，改API_HOST = "0.0.0.0"，外网访问需要服务器开放对应端口防火墙

## ⚙️ 插件配置

在 AstrBot 插件配置界面中，您可以根据实际情况调整以下参数：

### 接入模式与基础配置

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `deploy_mode` | String | `manual` | 后端接入模式：`manual`=独立链接（自行部署后端），`auto`=一键托管（插件自动部署管理）。切换后需重载插件。 |
| `overstats_api_url` | String | `http://127.0.0.1:18080/api/v2` | Overstats 服务 API 地址（manual 模式使用，auto 模式忽略） |

### 一键托管模式配置（auto 模式生效）

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `backend_repo_url` | String | `https://github.com/Zzzzzzouhang/Overstats.git` | 后端仓库地址，用于 git clone/pull |
| `backend_host` | String | `127.0.0.1` | 后端监听地址，外网访问需改为 `0.0.0.0` |
| `backend_port` | Int | `18081` | 后端监听端口 |
| `auto_start_on_boot` | Bool | `false` | 插件加载时自动启动后端（首次部署仍需手动执行 `/ow部署`） |
| `dashen_accounts` | TemplateList | — | 大神账号配置（auto 模式必填），每项含 `name`/`role_id`/`token` |
| `ow_esports_api_key` | String | — | PandaScore 赛事 API Key（可选） |
| `analysis_base_url` | String | — | AI 锐评接口 Base URL（可选） |
| `analysis_api_key` | String | — | AI 锐评接口 API Key（可选） |
| `analysis_model` | String | — | AI 锐评模型名（可选） |
| `analysis_persona_prompt` | Text | — | AI 锐评人设提示词（可选） |

> ⚠️ auto 模式下，后端配置项（端口、账号、AI 分析等）修改后需执行 `/ow重启后端` 或 `/ow部署` 才会生效（会重新生成 config.py）。

## 📋 指令大全

您可以在群聊中发送 `/owhelp` 或 `/ow菜单` 查看精美的可视化交互菜单。以下为 `main.py` 中注册的核心指令及别称汇总：

### 1. 基础与绑定
* `/大神绑定 [战网ID]` (别称：`/绑定`) — *绑定战网账号（例：`/绑定 Player#12345`）。群聊内直接发送符合规范的战网 ID 也会被自动识别绑定。*
* `/所有指令` (别称：`/别称`) — *展示所有插件指令及其全部对应的别称列表。*
* `/owhelp` (别称：`/ow菜单`, `/ow帮助`, `/OW帮助`, `/help`) — *显示快捷指令菜单。*

### 2. 数据与战绩查询
* `/今日总结` (别称：`/今日`, `/今日数据`) — *生成过去 24 小时内的对局大数据总结卡片。*
* `/昨日总结` (别称：`/昨日`, `/昨日数据`, `/昨天数据`, `/昨天`) — *统计并生成昨日战绩数据卡片. *
* `/周度总结` (别称：`/本周总结`, `/本周数据`, `/本周`) — *统计本周战绩大数据总结，耗时较长（约 30-60 秒）。*
* `/大神数据 [战网ID/模式] [模式/战网ID]` (别称：`/详情卡片`, `/战绩查询`, `/数据`) — *查看玩家详情卡片（模式支持：快速/quick、竞技/competitive）。*
* `/大神对局 [战网ID]` (别称：`/最近对局`, `/战绩`, `/对局`) — *拉取最近 20 局的对局列表。*
* `/单局详细 [数字索引] [战网ID]` (别称：`/单局`) — *查看对应序号的单局多图详细战绩。在群聊拉取对局后，**直发数字 1~20** 同样能触发对应的单局详细分析。*
* `/同玩查询 [战网ID1] [战网ID2]` (别称：`/开黑胜率`) — *深度分析两位玩家一同游玩开黑时的战绩与胜率。*

### 3. 指数与图表
* `/历史段位` (别称：`/历届段位`) — *追溯玩家的历史天梯段位记录。*
* `/快速强度` (别称：`/快速强度指数`) — *评估玩家在快速模式下的强度指数。*
* `/竞技强度` (别称：`/竞技强度指数`) — *评估玩家在竞技天梯模式下的强度指数。*
* `/快速英雄云图` (别称：`/快速云图`) — *获取并生成指定赛季的快速模式英雄使用率云图。*
* `/竞技英雄云图` (别称：`/竞技云图`) — *获取并生成指定赛季的竞技模式英雄使用率云图。*

### 4. 游戏生态与资讯
* `/威能 [英雄名]` — *提取指定英雄的核心威能、机制数据图。*
* `/ow英雄 [英雄名]` — *读取指定英雄在当前天梯的 Pick 率历史走势图。*
* `/获取段位分布` — *统计天梯全服大盘全英雄数据排行与天梯环境分布。*
* `/banpick` (别称：`/全英雄排行`) — *获取本周天梯英雄大盘的选禁用排行。*
* `/商店` (别称：`/ow商店`) — *拉取今日精选商店在售皮肤商品。*
* `/皮肤搜索 [关键词]` — *检索包含指定关键词的精选上架皮肤商品卡片。*
* `/mappick` — *从最新补丁中检索当前赛季的地图池与轮换出场情况。*
* `/ow赛事` (别称：`/赛事`) — *获取实时职业赛事对阵及赛程信息。*
* `/ow活动` (别称：`/活动`) — *拉取当前版本限时限时节日或赛季大活动公告卡片。*
* `/ow更新 [日志类型]` (别称：`/版本更新`) — *拉取外服更新日志卡片（参数支持：`latest`, `small`, `big`）。*

### 5. 天梯排行榜
* `/省榜 [省份] [位置]` (别称：`/排行`) — *获取指定地区的大神天梯省榜（位置支持：`tank` / `dps` / `healer` / `open`）。*
* `/绝活榜 [省份] [英雄]` (别称：`/英雄省榜`) — *获取指定地区、特定英雄的大神专精绝活榜。*

### 6. 群组管理
* `/群设置` — *查看当前群组的功能配置状态（所有群成员可用）。*
* `/群设置 提示 开|关` — *切换「首次提示后不再提示」功能（仅群管理员/群主可用）。开启后，每个用户每日首次指令会显示等待提示，后续指令直接返回结果。*
* `/群设置 追加提示 开|关` — *切换「追加交互提示」功能（仅群管理员/群主可用）。开启后，错误消息会追加「请手动@机器人或点击快捷指令」的提示。默认开启。*

### 7. 系统维护
* `/维护 [内容]` — *设置维护模式（仅 AstrBot 系统管理员可用）。开启后，所有用户发送数据查询指令（如今日总结、大神数据、省榜等）均会收到指定的维护内容回复。基础指令（/owhelp、/绑定、/群设置）不受影响。*
* `/维护 取消` — *关闭维护模式（仅 AstrBot 系统管理员可用）。*

### 8. 运维工具（所有模式通用）
* `/ow连接测试` — *测试 Overstats 后端连接是否正常（仅 AstrBot 系统管理员可用）。直接返回后端 `/healthz` 接口的原始响应。*
* `/ow部署状态` — *查看后端接入模式与运行状态（仅 AstrBot 系统管理员可用）。显示当前接入模式（auto/manual）、运行状态、监听地址、后端目录、git 版本、进程状态等。两种模式均可使用。*

### 9. 一键部署（仅 auto 托管模式）
> 以下指令仅在 `auto`（一键托管）模式下生效，需先在配置面板切换模式并重载插件。

* `/ow部署` — *一键部署后端（仅 AstrBot 系统管理员可用）。自动完成代码获取、虚拟环境创建、依赖安装、配置生成、服务启动、健康检查全流程。首次使用必执行。*
* `/ow更新后端` — *拉取最新代码并重启（仅 AstrBot 系统管理员可用）。用于跟进原项目 Overstats 的更新，自动执行 git pull → 安装依赖 → 重新生成配置 → 重启。*
* `/ow停止后端` — *停止后端进程（仅 AstrBot 系统管理员可用）。*
* `/ow重启后端` — *重启后端进程（仅 AstrBot 系统管理员可用）。配置面板修改后端配置后需执行此指令生效。*
* `/ow部署日志` — *查看后端运行日志（仅 AstrBot 系统管理员可用）。显示最近 50 行后端实时输出（内存缓冲），用于快速排查问题。*
* `/ow后端日志` — *查看后端持久化日志（仅 AstrBot 系统管理员可用）。从专用日志文件中提取最新 10 条记录，日志跨后端重启保留，容量上限 300 条。*

### 10. 后端卸载（仅 auto 托管模式）
> 以下指令仅在 `auto`（一键托管）模式下生效。后端卸载与插件卸载**相互独立**：卸载后端不影响插件其他功能，manual 模式仍可正常使用。

> ⚠️ **安全说明**：后端卸载严格按照「先停止进程 → 再删除文件」顺序执行，确保 SQLite 数据库不会因文件占用而损坏。卸载操作不可逆，数据库文件删除后无法恢复。

* `/ow卸载后端` — *预览卸载影响（仅 AstrBot 系统管理员可用）。显示后端代码目录、虚拟环境目录、磁盘占用、运行中进程、将被删除的数据库文件列表等信息，供用户确认后再执行卸载。*
* `/ow卸载后端执行 确认` — *执行完整卸载（仅 AstrBot 系统管理员可用）。删除后端代码目录（含数据库）+ 虚拟环境，释放全部占用空间。卸载后如需重新使用需执行 `/ow部署`。*
* `/ow卸载后端执行 仅代码` — *仅删除后端代码目录（含数据库），保留虚拟环境。适合代码损坏需要重新 clone 的场景。*
* `/ow卸载后端执行 仅venv` — *仅删除虚拟环境，保留后端代码。适合依赖损坏需要重建 venv 的场景。*
* `/ow卸载后端执行 强制` — *强制删除全部后端资源。当后端进程无法正常停止时使用，会先尝试强制杀进程再删除文件。*

> 💡 **与 AstrBot 插件卸载的区别**：
> - AstrBot 插件卸载（`delete_data=True`）会删除整个 `data/plugin_data/overstats_full/` 目录，包括后端代码、venv、临时图片、群组配置等**所有**插件数据。
> - `/ow卸载后端` 是**独立的、细粒度的**后端卸载，仅删除后端相关资源（代码+venv+数据库），不影响插件其他数据。
> - 推荐流程：先执行 `/ow卸载后端` 预览 → 确认后执行 `/ow卸载后端执行 确认` → 再通过 AstrBot 管理面板卸载插件。
