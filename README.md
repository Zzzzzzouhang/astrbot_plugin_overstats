# astrbot_plugin_overstats

一款为 [AstrBot (阿斯特拉机器人)](https://github.com/Soulter/AstrBot) 打造的守望先锋数据查询插件。本插件作为桥梁，连接了由网易大神接口驱动的 [Overstats](https://github.com/AddOneSecondL/Overstats) 后端服务，为您的群聊带来全方位的守望先锋战绩与资讯查询体验。

> ⚠️ **声明**：本插件的大部分代码并非人类编写（由 AI 协作完成），如有未能预料的异常，欢迎提交 Issue。

---

## 🌟 核心特性

* **极速绑定**：支持 `/绑定` 指令。在群聊中直接发送符合规范的战网 ID（如 `Player#12345`），插件会自动截获并自动完成账号绑定。
* **全景数据大盘**：
    * **战绩总结**：提供今日、昨日、周度大数据总结卡片。若今日无对局，会自动尝试拉取昨日总结。
    * **对局分析**：支持最近对局详情。更可通过在群聊中**直发数字 1~20**，一键拉取单局多图的超详细战绩分析。
    * **天梯评估**：历史历届段位追溯、快速/竞技英雄云图（Treemap 矩形树图）、开黑同玩胜率、天梯强度指数评估。
* **国服/外服资讯**：全服段位分布图、Ban/Pick 胜率排行、每周精选商店、实时赛事对阵图、赛季地图池、皮肤搜索、外服版本补丁说明。
* **专精排行榜**：支持按省份/位置查询天梯省榜（Tank/DPS/Support/Open），以及单英雄专精绝活榜。
* **平台动态适配**：原生支持 QQ 官方机器人平台。在官方环境下会自动启用动态 Markdown 按钮标签（`<qqbot-cmd-input>`）并进行编码处理，提供点击交互体验；在其他平台则自动剥离标签转为纯文本，确保格式完美。

---

## 🛠️ 前置准备

本插件**仅用于 AstrBot 与 Overstats 后端通讯**。在安装本插件之前，您**必须先在服务器上部署原项目服务**。

1. 请前往 [AddOneSecondL/Overstats](https://github.com/AddOneSecondL/Overstats) 仓库，按照其说明文档完成服务部署。
2. 确保 Overstats 后端的 API 端口（默认 `18080`）可以被 AstrBot 所在的服务器正常访问。

---

## 🚀 安装方式

推荐优先使用 AstrBot 插件市场的仓库安装功能：

1. 打开 AstrBot 管理面板。
2. 进入 **插件市场** -> **通过 GitHub 仓库安装**。
3. 输入以下仓库地址并点击安装：
   ```text
   Zzzzzzouhang/astrbot_plugin_overstats
   ```
4. 重启 AstrBot。

## ⚙️ 插件配置

在 AstrBot 插件配置界面中，您可以根据实际情况调整以下参数：

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `overstats_api_url` | String | `http://127.0.0.1:18080/api/v2` | 部署的 Overstats 服务 API 根路径 |

## 📋 指令大全

您可以在群聊中发送 `/owhelp` 或 `/ow菜单` 查看精美的可视化交互菜单。以下为 `main.py` 中注册的核心指令及别称汇总：

### 1. 基础与绑定
* `/大神绑定 [战网ID]` (别称：`/绑定`) — *绑定战网账号（例：`/绑定 Player#12345`）。群聊内直接发送符合规范的战网 ID 也会被自动识别绑定。*
* `/所有指令` (别称：`/别称`) — *展示所有插件指令及其全部对应的别称列表。*
* `/owhelp` (别称：`/ow菜单`, `/ow帮助`, `/OW帮助`, `/help`) — *显示快捷指令菜单。*

### 2. 数据与战绩查询
* `/今日总结` (别称：`/今日`, `/今日数据`) — *生成过去 24 小时内的对局大数据总结卡片。*
* `/昨日总结` (别称：`/昨日`, `/昨日数据`, `/昨天数据`, `/昨天`) — *统计并生成昨日战绩数据卡片. *
* `/周度总结` (别称：`/本周总结`, `/本周数据`, `/本周`) — *统计本周战绩大数据总结，耗时较长（约 30-60 秒）。*
* `/大神数据 [战网ID/模式] [模式/战网ID]` (别称：`/详情卡片`, `/战绩查询`, `/数据`) — *查看玩家详情卡片（模式支持：快速/quick、竞技/competitive）。*
* `/大神对局 [战网ID]` (别称：`/最近对局`, `/战绩`, `/对局`) — *拉取最近 20 局的对局列表。*
* `/单局详细 [数字索引] [战网ID]` (别称：`/单局`) — *查看对应序号的单局多图详细战绩。在群聊拉取对局后，**直发数字 1~20** 同样能触发对应的单局详细分析。*
* `/同玩查询 [战网ID1] [战网ID2]` (别称：`/开黑胜率`) — *深度分析两位玩家一同游玩开黑时的战绩与胜率。*

### 3. 指数与图表
* `/历史段位` (别称：`/历届段位`) — *追溯玩家的历史天梯段位记录。*
* `/快速强度` (别称：`/快速强度指数`) — *评估玩家在快速模式下的强度指数。*
* `/竞技强度` (别称：`/竞技强度指数`) — *评估玩家在竞技天梯模式下的强度指数。*
* `/快速英雄云图` (别称：`/快速云图`) — *获取并生成指定赛季的快速模式英雄使用率云图。*
* `/竞技英雄云图` (别称：`/竞技云图`) — *获取并生成指定赛季的竞技模式英雄使用率云图。*

### 4. 游戏生态与资讯
* `/威能 [英雄名]` — *提取指定英雄的核心威能、机制数据图。*
* `/ow英雄 [英雄名]` — *读取指定英雄在当前天梯的 Pick 率历史走势图。*
* `/获取段位分布` — *统计天梯全服大盘全英雄数据排行与天梯环境分布。*
* `/banpick` (别称：`/全英雄排行`) — *获取本周天梯英雄大盘的选禁用排行。*
* `/商店` (别称：`/ow商店`) — *拉取今日精选商店在售皮肤商品。*
* `/皮肤搜索 [关键词]` — *检索包含指定关键词的精选上架皮肤商品卡片。*
* `/mappick` — *从最新补丁中检索当前赛季的地图池与轮换出场情况。*
* `/ow赛事` (别称：`/赛事`) — *获取实时职业赛事对阵及赛程信息。*
* `/ow活动` (别称：`/活动`) — *拉取当前版本限时限时节日或赛季大活动公告卡片。*
* `/ow更新 [日志类型]` (别称：`/版本更新`) — *拉取外服更新日志卡片（参数支持：`latest`, `small`, `big`）。*

### 5. 天梯排行榜
* `/省榜 [省份] [位置]` (别称：`/排行`) — *获取指定地区的大神天梯省榜（位置支持：`tank` / `dps` / `healer` / `open`）。*
* `/绝活榜 [省份] [英雄]` (别称：`/英雄省榜`) — *获取指定地区、特定英雄的大神专精绝活榜。*
