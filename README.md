# astrbot-plugin-overstats
用于连接overstats守望先锋插件

https://github.com/AddOneSecondL/Overstats
守望先锋数据查询，基于网易大神接口，支持玩家资料、战绩、段位、强度分析、总结、英雄选取率、商店、补丁说明等

1.需要在服务器部署原项目，这个插件仅用于astrbot与原项目通讯，插件配置界面提供了配置选项
2.大部分代码并非人类编写

📌 Overstats 查询菜单
🔗 ➤ 绑定「战网 ID」
📋 ➤ 今日 ➤ 昨日 ➤ 本周
📊 ➤ 大神数据 ➤ 大神对局 ➤ 单局详细「数字」
📈 ➤ 快速强度 ➤ 竞技强度 ➤ 获取段位分布
🗺️ ➤ 快速云图 ➤ 竞技云图
🏆 ➤ 省榜「省份」「位置」 ➤ 绝活榜「省份」「英雄」
⚔️ ➤ 威能「英雄名」 ➤ ow 英雄「英雄名」 ➤ banpick ➤ mappick
🌍 ➤ 同玩查询「ID1」「ID2」 ➤ 商店 ➤ 皮肤搜索 ➤ ow 赛事
📰 ➤ ow更新「latest/small/big」
💡 提示：在「大神对局」图片发出来后，直接回复数字即可看单局详细。
发送「别称」可查看所有指令对应别称列表。

📋 【Overstats 指令及别称大全】

🔹 基础与绑定类：
• `owhelp` (别称：ow菜单, ow帮助, OW帮助, help)
• `所有指令` (别称：别称)
• `大神绑定` (别称：绑定)

🔹 数据查询类：
• `大神数据` (别称：详情卡片, 战绩查询, 数据)
• `大神对局` (别称：最近对局, 战绩)
• `单局详细` (别称：单局)
• `同玩查询` (别称：开黑胜率)

🔹 总结类：
• `今日总结` (别称：今日, 今日数据)
• `昨日总结` (别称：昨日, 昨日数据, 昨天数据, 昨天)
• `周度总结` (别称：本周总结, 本周数据, 本周)

🔹 图表与排行类：
• `历史段位` (别称：历届段位)
• `快速强度` (别称：快速强度指数)
• `竞技强度` (别称：竞技强度指数)
• `快速英雄云图` (别称：快速云图)
• `竞技英雄云图` (别称：竞技云图)
• `省榜` (别称：排行)
• `绝活榜` (别称：英雄省榜)
• `banpick` (别称：全英雄排行)

🔹 游戏资讯类：
• `威能`, `ow英雄`, `获取段位分布`, `mappick`, `皮肤搜索`
• `商店` (别称：ow商店)
• `ow赛事` (别称：赛事)
• `ow活动` (别称：活动)
• `ow更新` (别称：版本更新)
