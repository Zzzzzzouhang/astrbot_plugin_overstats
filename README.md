# astrbot-plugin-overstats
用于连接overstats守望先锋插件
https://github.com/AddOneSecondL/Overstats

📌 守望先锋 Overstats 查询菜单：
=======================
👉【数据/战绩总结】
   /大神绑定 [战网ID] - 绑定QQ与战网账号
   直接发送战网ID - 快速自动绑定/更新战网账号
   @电子路灯 [战网ID] - 快速自动绑定/更新战网账号
   /大神数据 (战网ID) - 查询玩家详情卡片
   /大神对局 (战网ID) - 查询最近对局列表
   /今日总结 (战网ID) - 查询今日战绩总结（无记录自动查昨日）
   /昨日总结 (战网ID) - 查询昨日战绩数据
   /周度总结 (战网ID) - 查询本周数据总结
   /历史段位 (战网ID) - 查询历届赛季段位
   /同玩查询 [战网ID1] [战网ID2] - 查询两人开黑胜率
👉【指数/英雄分析】
   /快速强度指数 (战网ID)
   /竞技强度指数 (战网ID)
   /威能 [英雄名]
   /ow英雄 [英雄名]
👉【综合/赛事】
   /商店 /ow赛事 /ow活动 /皮肤搜索
=======================
💡 带()可省略，需先绑定账号。
